# MyAgent Central Menu & Quick Command Guide

Welcome to the command dashboard for the **MyAgent AI Software Engineering Operating System**.

When activated, present the directory of specialized specialist roles and available capabilities to streamline task execution:

---

## Quick Action Menu

| Command / Skill | Capability | When to Use | Example Command |
|---|---|---|---|
| `/my-code-graph` | **Code Graph Intelligence** | AST parsing, symbol lookup, dependency graphs, caller/callee relations | *"Use `my-code-graph` to locate the webhook handler function"* |
| `/my-plan` | **Planner & Whole-Plan** | Multi-step task decomposition and autonomous multi-agent orchestration | *"Use `my-plan` to design the migration plan for feature X"* |
| `/my-ui` | **UI Specialist** | Non-generic UI design, DESIGN.md contract, sector archetypes, a11y | *"Use `my-ui` to create a responsive admin dashboard layout"* |
| `/my-test` | **Test Runner & Verification** | Deterministic automated testing (`pytest`, `go test`, `npm test`) & gates | *"Use `my-test` to execute the test suite and verify changes"* |
| `/my-security` | **Security, SAST & Red-Team** | Static analysis, secret scanning, prompt defense, OWASP LLM testing | *"Use `my-security` to audit the entire repository"* |
| `/my-handoff` | **Explicit Handoff** | Guardrail-enforced task delegation between specialized agent roles | *"Use `my-handoff` to transfer from Backend Coder to Tester"* |
| `/my-release` | **Release & SBOM** | Release readiness gate, CycloneDX 1.5 SBOM, SHA-256 attestation | *"Use `my-release` to generate SBOM and verify release readiness"* |
| `/my-memory` | **Memory & Knowledge** | Cross-session learning consolidation and repository docs search | *"Use `my-memory` to find architecture decisions in docs"* |
| `/my-review` | **Git Review & Reply** | Batch review GitHub PR threads, analyze code diffs, and push replies | *"Use `my-review` to inspect and answer comments on PR #12"* |
| `/my-status` | **System Status & Budget** | Control Plane status, circuit breaker health, token budget tracking | *"Use `my-status` to inspect current execution budget and provider health"* |

---

## Quick Guidance
1. Trigger any capability by its slash command (e.g., `/my-ui`, `/my-plan`, `/my-security`) or conversational instruction.
2. Switch active project context anytime with: *"Switch active project to `<project_name>`"*.
