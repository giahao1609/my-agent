\# MyAgent



MyAgent is a full AI coding agent designed for software development.



\## Goals



MyAgent will provide:



\- Agent orchestration

\- Planning and execution

\- Repository understanding

\- Chat memory

\- Skill memory

\- Project wiki

\- Code graph

\- Multi-agent workflows

\- Filesystem tools

\- Terminal tools

\- Git tools

\- Browser automation

\- Playwright testing

\- Sandbox execution

\- MCP integration

\- Evaluation

\- Self-improvement

\- Security controls



\## Architecture



Main modules:



\- `core/` — Agent core and orchestration

\- `agents/` — Specialized agents

\- `memory/` — Chat, skill, wiki and code-graph memory

\- `tools/` — Filesystem, terminal, git and browser tools

\- `sandbox/` — Isolated code execution

\- `mcp/` — MCP interface

\- `skills/` — Reusable agent skills

\- `evaluation/` — Agent evaluation and benchmarks

\- `integrations/` — External integrations



\## Development Status



Current phase: Phase 0 — Foundation.



\## Python



Python 3.13+



\## Project



This project uses selected concepts and modules from upstream open-source

projects. Upstream repositories are references/building blocks and are not

merged wholesale into MyAgent.
